# CHEMx19A — Exam III sheets

Two documents, built from markdown source:

| file | pages | what it is |
|---|---|---|
| `chem_x19a_mt3_instruction_sheet.pdf` | 2 | the exam sheet — 23 numbered boxes, one per study-guide question |
| `chem_x19a_mt3_info_sheet.pdf` | 1 | chapter reference (Ch 7 / 8 / 9), for studying |

## Reproduce

This project is managed with [uv](https://docs.astral.sh/uv/). It also needs
two sets of native libraries: **poppler** (for `pdf2image`) and the **GTK**
stack pango/cairo/gdk-pixbuf (for `weasyprint`).

**macOS**

    brew install poppler pango cairo gdk-pixbuf libffi
    make build

**Ubuntu / Debian / WSL**

    sudo apt-get install -y poppler-utils libpango-1.0-0 libpangoft2-1.0-0 \
        libcairo2 libgdk-pixbuf-2.0-0 libffi-dev
    uv run python build_all.py

`make build` (macOS) sets `DYLD_FALLBACK_LIBRARY_PATH` to the Homebrew lib
directory so WeasyPrint can find the GTK libraries, then runs the build under
uv. On Linux those libraries are on the default loader path, so plain
`uv run python build_all.py` works. `uv` installs the pinned dependencies from
`uv.lock` into `.venv/` automatically on first run.

`build_all.py` renders the LaTeX images, measures every box at the real
column width, solves the optimal column split, then renders the PDFs. It
asserts the page counts (2 and 1) and fails loudly if a change pushes
either sheet over.

## Editing

Edit content only in:

- `qsection.md` — instruction sheet. One `<div class="problem">` per box,
  titled `#### (n) Description` where `n` is the study-guide question number.
- `info_sheet.md` — info sheet, one `<div class="chbox">` per chapter.

Then re-run `build_all.py`. Page and column breaks are computed, never
hand-placed — don't add `<!--pagebreak-->` or `<!--colbreak-->` yourself.

### Markup traps

1. A bare `<` before a letter is parsed as an HTML tag and silently
   corrupts the layout. Write `&lt;` — e.g. `s &lt; p &lt; d &lt; f`.
2. Adjacent divs need `</div>` on the line immediately before the next
   `<div ...>`, with no blank line between, or `md_in_html` emits an
   unbalanced tag and the columns collapse.
3. **Equation images are black text on transparent.** They vanish on the
   black `####` header bars. If you need one inside a header, render a
   white variant — see `WHITE_ON_DARK` in `render_eq_exam3.py`, which is
   why `s_zeff_w.png` exists alongside `s_zeff.png`.
4. **`white-space: nowrap` tables overflow instead of wrapping.** The
   `.emtable` and `.lut` classes set it, so a too-wide row silently bleeds
   past the column edge rather than failing the build. Column 1 ends at
   x=300.2pt, column 2 starts at 313.1pt (letter, 0.3in margins, 2 cols).
   Check with the snippet under "Verifying layout" below.

### Verifying layout

`build_all.py` only asserts page count, not horizontal overflow. To check a
table actually fits:

    python3 -c "
    import pdfplumber
    with pdfplumber.open('chem_x19a_mt3_instruction_sheet.pdf') as pdf:
        pg = pdf.pages[0]
        bad = [w for w in pg.extract_words() if 300.2 < w['x1'] < 313.1]
        print('overflow:', [w['text'] for w in bad] or 'none')
    "

## Lookup-table convention

Boxes (1)-(3) are built as unit-pair lookup grids rather than procedures.
The corner cell names both axes (`λ ↓ ν →`), so units are stated once in
the headers instead of repeated in every row label. Constants are
pre-multiplied so a value can be plugged straight in with no unit
conversion step:

- (2) each cell is **c expressed in that unit pair**, so `λ × ν = cell`
  holds in both directions — divide the cell by whichever you have.
- (3) each cell is **hc** (or **h**) folded with the nm/mol conversions.

If you change a constant, re-verify it. Every cell in (2) and (3) was
checked against a 500 nm photon: 6.00×10¹⁴ Hz, 3.98×10⁻¹⁹ J, 240 kJ/mol.

## Numbering

The study guide's summary section resolves to 18 top-level MC topics, then
Lewis structures, then 4 word problems = 23 questions, matching its own
points table (Q1–18 @ 6.5, Q19 @ 26, Q20–23 @ 14/14/15/14 = 200).

Beware: the `.docx` flattens all indent levels to identical dashes. Bullets
ending in `:` are headers owning the ones beneath them — counting every dash
as a topic gives 21 and does not match the exam.
