### B. Oxidation

#### (1) LEO / GER

being oxidized = reducing agent = ↑ charge = LEO

being reduced = oxidizing agent = ↓ charge = GER

#### (2) Oxidation Number Rules

*(elements, groups, F, H, O, rule 1)*

1. Σ ON = total charge (0 if neutral; = charge if ion)
2. Free element = 0
3. Group 1A = +1
4. Group 2A = +2
5. Group 3A = +3 or +1 (B = +3)
6. Group 4A = +4 or +2 (except C, Si)
7. H = +1 with nonmetals; −1 with metals/metalloids
8. F = −1 (always)
9. Cl, Br, I = −1 (except with O)
10. O = −2; except peroxide O₂²⁻ (−1), superoxide O₂⁻ (−½), ozonide O₃⁻ (−⅓), positive with F

## Reaction Types

#### Combination — A + B → AB

| Type | Example |
|---|---|
| metal + nonmetal → salt | 2Na(s) + Cl₂(g) → 2NaCl(s) |
| metal oxide + H₂O → metal hydroxide | CaO + H₂O → Ca(OH)₂ |
| nonmetal oxide + H₂O → oxyacid | CO₂ + H₂O → H₂CO₃ |

#### Decomposition — AB → A + B (watch diatomics)

| Type | Example |
|---|---|
| Metal oxides | 2PbO₂(s) →Δ 2PbO(s) + O₂(g) |
| Carbonates | CaCO₃(s) →Δ CaO(s) + CO₂(g) |
| H₂O₂ → steam + O₂ | 2H₂O₂(l) → 2H₂O(g) + O₂(g) |

#### Single Displacement

A + BC → AC + B (A = more reactive metal; kicks out B)

A + BC → BA + C (A = more reactive halogen; kicks out C)

| Type | Example |
|---|---|
| metal + acid → H₂ + salt | 2Al(s) + 3H₂SO₄(aq) → Al₂(SO₄)₃(aq) + 3H₂(g) |
| metal + H₂O → H₂ + metal hydroxide/oxide | 2Na(s) + 2H₂O(l) → 2NaOH(aq) + H₂(g) |
| metal (or halogen) + salt → metal (or halogen) + salt | Fe(s) + CuSO₄(aq) → Cu(s) + FeSO₄(aq)<br>Cl₂(g) + 2KI(aq) → I₂(s) + 2KCl(aq) |

#### Double Displacement — AB + CD → AD + CB (must be s, l, g)

*needs a solid, liquid, or gas product*

| Type | Example |
|---|---|
| acid + base → salt + H₂O + heat | HCl(aq) + NaOH(aq) → NaCl(aq) + H₂O(l) + heat |
| metal oxide (base) + acid → salt + H₂O + heat | CuO(s) + 2HNO₃(aq) → Cu(NO₃)₂(aq) + H₂O(l) + heat |
| precipitate forms (insoluble → (s)) | 2BaCl₂(aq) + 2AgNO₃(aq) → 4AgCl(s) + 2Ba(NO₃)₂(aq) |
| gas forms | H₂SO₄(l) + NaCl(s) → NaHSO₄(aq) + HCl(g) |

## Polyatomic Ions

OH⁻ hydroxide · CO₃²⁻ carbonate · SO₃²⁻ sulfite · SO₄²⁻ sulfate · NO₂⁻ nitrite · NO₃⁻ nitrate · ClO₃⁻ chlorate · ClO₄⁻ perchlorate · PO₄³⁻ phosphate · MnO₄⁻ permanganate · NH₄⁺ ammonium

#### (1) Balance a reaction — combustion or polyatomic
1. Write the unbalanced skeleton equation.
2. For combustion (CₓHᵧ + O₂): balance C first, then H, then O last.
3. For polyatomic ions: treat the whole ion (e.g. SO₄²⁻) as one unit if it survives intact.
4. Adjust coefficients only — never change subscripts.
5. Check each element balances and total charge is equal on both sides.

#### (2) Write the net ionic equation
1. Write the balanced molecular equation with states.
2. Split all *aqueous strong* electrolytes into ions (total ionic eqn).
3. Keep solids (s), liquids (l), gases (g), and weak electrolytes intact.
4. Cancel spectator ions (identical on both sides).
5. Identify what remains — that's the net ionic equation.

#### (3) Oxidation number of an element
1. Assign known values: free element = 0; group 1A = +1; 2A = +2; F = −1; O = −2 (peroxide −1); H = +1 (−1 with metals).
2. Set the sum of all oxidation numbers = overall charge (0 if neutral).
3. Solve algebraically for the unknown element.

#### (4) Redox half-reactions / agents
1. Assign oxidation numbers to every element, both sides.
2. Write each half-reaction; add e⁻ to the side that balances the charge (LEO / GER).

- Element whose ON **increases** = oxidized = the **reducing agent**.
- Element whose ON **decreases** = reduced = the **oxidizing agent**.

1. Convert mass of solute → moles (÷ molar mass).

3. Divide moles by liters.

#### (11) Kinetic theory — concepts
- Gas particles are tiny, in constant random motion, collisions elastic.
- Higher T → higher average speed.
- Heavier molecule → lower speed (at same T).
- At the **same T**, all gases have the **same average KE**.

#### (13) Ideal vs. real gas
- Gases deviate at **high pressure** or **low temperature**.
- High P → real gas occupies **larger V** than ideal predicts (particle volume is no longer negligible vs. container).
- Low T → real gas pressure is **lower** than ideal predicts (IMF pull particles inward, softening collisions with the wall).

#### (26–29) Word Problems

#### % yield with limiting reactant

<img src="assets/s2_yield.png" class="eq">

1. Convert given mass of each reactant → moles.
2. Use mole ratios to find which runs out first = **limiting reactant**.
3. From the limiting reactant, compute theoretical mass of product.
4. % yield = (actual ÷ theoretical) × 100.

#### Acid/base titration
1. Write & balance the neutralization reaction (note acid:base mole ratio).
2. Moles of known = V (in L) × M.
3. Apply the mole ratio to get moles of unknown.
4. Divide by the unknown's volume (L) → its molarity.

#### Gas stoichiometry
1. Balance the reaction.
2. Convert the given (mass or gas) → moles.
3. Apply the mole ratio to the target gas.
4. Convert moles of gas → volume via PV = nRT (or 22.4 L/mol at STP).

#### Calorimetry (heat loss to calorimeter + water)

<img src="assets/s2_calor.png" class="eq">

1. Compute heat into water: q_water = m·C·ΔT (water: 1 mL = 1 g).
2. Compute heat into calorimeter: q_cal = C_cal·ΔT.
3. q_rxn = −(q_water + q_cal).
4. Divide by grams (kJ/g) or by **moles of limiting reactant** (kJ/mol).

- **Bomb (const V):** often only q_cal matters → q_rxn = −C_cal·ΔT; exothermic combustion → **negative** ΔE, ÷ mol.

#### Hess's law

<img src="assets/s2_hess.png" class="eq">

1. Arrange given equations so they add to the target reaction.
2. Cancel identical species on opposite sides.
3. Sum the adjusted ΔH values = ΔH of the target reaction.

- **Reverse** an equation → flip the sign of its ΔH.
- **Scale** an equation → multiply its ΔH by the same factor.
